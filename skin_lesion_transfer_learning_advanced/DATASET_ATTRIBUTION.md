# Dataset attribution and licence notes

This project is code only; it does not redistribute HAM10000 images or metadata.

Before downloading or using any dataset, review the terms shown at the source. The ISIC 2018 aggregate training data page marks the HAM10000 dataset as CC BY-NC. This indicates attribution and non-commercial restrictions apply. Do not use the dataset or a model trained on it for commercial purposes unless you have confirmed the rights and obtained any required permission.

Suggested attribution:
> HAM10000 Dataset: © ViDIR Group, Department of Dermatology, Medical University of Vienna; https://doi.org/10.1038/sdata.2018.161

Recommended paper citation:
Tschandl, P., Rosendahl, C. & Kittler, H. The HAM10000 dataset, a large collection of multi-source dermatoscopic images of common pigmented skin lesions. Scientific Data 5, 180161 (2018). https://doi.org/10.1038/sdata.2018.161

Dataset source: https://challenge.isic-archive.com/data/

## Optional rash / skin-condition research data
Google's SCIN dataset contains consented volunteer contributions and dermatologist labels for common skin conditions, along with skin-tone-related annotations. Review its official dataset documentation and terms before use:
- https://huggingface.co/datasets/google/scin
- https://research.google/blog/scin-a-new-resource-for-representative-dermatology-images/

SCIN is not a ready-made four-class oily/dry/normal/combination skin-type dataset, and it should not be treated as a definitive allergy diagnosis dataset. Confirm current licence, consent, and usage terms before any training or redistribution.
